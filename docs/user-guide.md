# 用户指南

## 基本概念

- 文档 A / 文档 B：一次对齐的两份自然文档，不预设谁更权威。
- 关系：两侧若干内容块的直接对应，可为 1:1、N:1、1:M、N:M 或单侧缺失。
- 工作报告：保存对齐、修订、AI 与审核状态的 JSON 文件。
- 覆写源文档：把报告重放后的正文明确写回输入文件。

## 推荐流程

1. 打开两份文档并运行对齐。
2. 检查低分、非 1:1 和单侧缺失关系。
3. 进行人工校订，按需调用 AI 审校并逐条确认建议。
4. 使用“保存工作报告”保存进度；自动保存也只更新报告。
5. 若希望原 Markdown 接纳校订，选择“覆写源文档”，审阅两侧差异后确认。

“文档操作”中的“对齐策略”控制自动校订如何处理多对一关系：可以优先减少正文修改，也可以分别以文档 A 或文档 B 的段落结构为基准。它不是文件导出格式；切换策略本身不会写入正文，只有执行自动校订后才会更新工作报告。

关闭并重新打开同一对文档时，只要正文哈希未变化，程序可从报告恢复状态。若正文被外部修改，旧报告会被拒绝，需重新对齐。

## 阅读器输出

Dualign 不再维护 `repaired/` 目录。阅读器构建过程会临时重放报告并生成等行文本，完成后删除临时文件。无需在 GUI 中手动导出。

## 数据安全

“保存”不会碰源文件。“覆写源文档”会修改源文件且不额外生成 `.bak`；需要长期版本历史时，请把正文和报告纳入 Git 或其他备份系统。
